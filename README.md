# Teleprint

Telegram-бот для печати документов и фотографий на сетевом принтере через протокол IPP.

## Философия проекта

**Один контейнер — один принтер.** Без CUPS, без лишних демонов, без сложной конфигурации.

CUPS — мощная система, но избыточная для задачи «принять файл из Telegram и распечатать». Он требует отдельного демона, регистрации принтера через `lpadmin`, и добавляет слой абстракции который сложнее дебажить. Teleprint работает напрямую с принтером по IPP — так же как это делает AirPrint. Ghostscript нужен только если принтер не принимает PDF.

## Возможности

- Печать **PDF** — напрямую на принтер без конвертации (если принтер поддерживает)
- Печать **JPG / PNG** — автоматическая конвертация в PDF с подбором ориентации
- Поворот изображения на 90°
- Масштаб: 25% / 50% / 75% / 100%
- Количество копий (настраивается)
- Приватный бот — белый список пользователей
- Docker — деплой одной командой

## Требования

- Принтер с поддержкой **AirPrint / IPP** в локальной сети
- Docker и Docker Compose

## Быстрый старт

```bash
git clone https://github.com/amidexe/teleprint.git
cd teleprint
cp .env.example .env
nano .env
docker compose up -d
```

## Конфигурация (.env)

```env
# Обязательные
TELEGRAM_TOKEN=your_bot_token     # Токен от @BotFather
ADMIN_ID=123456789                # Ваш Telegram ID (узнать: @userinfobot)
PRINTER_HOST=192.168.1.100        # IP-адрес принтера

# Формат печати — главный параметр, зависит от модели принтера
PRINTER_FORMAT=urfgray            # см. таблицу ниже

# Опциональные
PRINTER_PORT=631                  # Порт IPP (по умолчанию 631)
PROXY_URL=socks5://127.0.0.1:1080 # Прокси для Telegram API
JOB_TTL_MINUTES=15                # Время жизни сессии (минуты)
MAX_COPIES=10                     # Максимум копий
DATA_DIR=/app/data                # Папка для users.json
```

### Выбор PRINTER_FORMAT

| Значение | Когда использовать | Примеры принтеров |
|----------|-------------------|-------------------|
| `urfgray` | Чёрно-белый принтер без поддержки PDF **(по умолчанию)** | Brother HL-L2370DN и большинство лазерных ч/б |
| `urfrgb` | Цветной принтер без поддержки PDF | Некоторые HP, Canon |
| `pdf` | Принтер принимает PDF напрямую | Kyocera ECOSYS, большинство современных офисных МФУ |

**Как понять что ставить:**
- Посмотрите спецификацию принтера: есть ли поддержка AirPrint и PDF через IPP
- Попробуйте `pdf` — если не печатает, переходите на `urfgray` или `urfrgb`
- Чёрно-белый принтер → `urfgray` почти всегда правильный выбор

### Как узнать IP принтера

- На дисплее принтера: Меню → Сеть → IP-адрес
- В роутере: список подключённых устройств
- Командой: `arp -a`

## Управление пользователями

Доступно только администратору:

| Команда | Описание |
|---------|----------|
| `/adduser 123456789` | Добавить пользователя по Telegram ID |
| `/deluser 123456789` | Удалить пользователя |
| `/users` | Список авторизованных пользователей |

Пользователи сохраняются в `data/users.json`.

## Использование

1. Отправьте боту PDF, фото или изображение
2. Настройте параметры кнопками:

```
➖  [ 1 коп. ]  ➕
[ 25% ] [ 50% ] [ 75% ] [ ·100%· ]
[ Повернуть (+0°) ]
[ Отмена ]  [ Печать ]
```

3. Нажмите **Печать**

## Архитектура

```
teleprint/
├── cmd/teleprint/          # Точка входа
└── internal/
    ├── access/             # Белый список пользователей (users.json)
    ├── bot/                # Telegram-бот, хендлеры, inline-кнопки
    ├── config/             # Загрузка .env
    ├── converter/          # JPG/PNG → PDF (масштаб, поворот)
    ├── printer/            # IPP-клиент + Ghostscript (PDF → URF)
    └── state/              # In-memory кэш заданий с TTL
```

**Поток данных:**
- PDF + `PRINTER_FORMAT=pdf` → принтер напрямую
- PDF + `PRINTER_FORMAT=urfgray/urfrgb` → Ghostscript → URF → принтер
- JPG/PNG → fpdf (PDF) → далее по схеме выше

## Технический стек

| Компонент | Решение |
|-----------|---------|
| Telegram Bot | [telebot v3](https://github.com/tucnak/telebot) |
| IPP протокол | [go-ipp](https://github.com/phin1x/go-ipp) |
| PDF → URF | [Ghostscript](https://www.ghostscript.com/) |
| Image → PDF | [go-pdf/fpdf](https://github.com/go-pdf/fpdf) |

## Docker Compose

```yaml
services:
  teleprint:
    build: .
    restart: unless-stopped
    network_mode: host      # Нужен для доступа к принтеру в локальной сети
    env_file: .env
    volumes:
      - ./data:/app/data
```

`network_mode: host` обязателен — контейнер должен видеть принтер напрямую по IP.
